# EK1D: one-dimensional copper electrokinetic reactive transport

**Version 2.1.0 — Ramin Mahyapour and Mahmood Sadat-Noori**

This repository contains the executable copper example accompanying *Electrokinetic reactive transport modeling for contaminant fate and remediation in low-permeability subsurface media: A critical review and evaluation framework*. Model settings correspond to Table 6; numerical checks are reported in Supplementary Table S3. The code runs independently of the retained reference data.

## Installation

The reference calculations used Python 3.12.14. From the code directory, install the pinned dependencies:

```bash
python -m pip install -r requirements.txt
```

The native backend requires a C++17 compiler (`g++` or `clang++`) on Linux, macOS or Windows Subsystem for Linux (WSL). It compiles the kernel locally. The Python backend requires no compiler but is much slower for fine grids. Native execution on Windows without WSL has not been verified. Automatic compiler detection checks `c++` and `g++`; if only `clang++` is available, set `CXX` to its executable path before running (for example, `export CXX=/usr/bin/clang++` in a Linux/macOS/WSL shell).

## Run the model

Run the selected 400-cell, 36-hour calculation:

```bash
python reproduce.py --case N400_cfl01 --output rerun_selected --backend native
```

Run all five cases, assess spatial and temporal refinement, and generate the article figures:

```bash
python reproduce.py --output rerun --backend native
```

Use `--backend python` for the compiler-free implementation. Each case covers 36 simulated hours; this is not the expected computer runtime. Fine-grid runs require millions of accepted steps. Existing case directories are not overwritten. A single-case run does not establish refinement agreement and does not automatically generate the article figure layout. Its `Figure7_corrected.*` and `Figure7_unbinned.*` outputs are diagnostic plots with instantaneous current. The manuscript uses `Figure7_Revised.*`, generated by `plot_article_figures.py`, with cumulative charge.

For a brief installation check:

```bash
python EK1D_tutorial.py --cells 20 --spatial-order 2 --time-order 2 --cfl 0.1 --max-step 3.75 --hours 0.01 --output-seconds 12 --backend native --out smoke
```

This short run checks execution only; it does not reproduce the article results.

## Companion data and verification

Two companion archives are supplied separately with the article materials or release attachments:

| Archive | Contents | Extraction |
|---|---|---|
| `EK1D_Numerical_Supplement.zip` | Five reference runs, numerical test scripts, archived check reports and three reference figures | Extract its contents into the code directory, preserving `data/` and `verification/` |
| `EKRT_Review_Evidence.zip` | Source inventory, study-level coding and count script for Supplementary Tables S1–S2 | Extract separately; it is independent of the transport model |

The numerical supplement does not replace any source-package file. Its test scripts must be beside `EK1D_tutorial.py`, not inside an extra enclosing folder. Read `NUMERICAL_SUPPLEMENT.md` after extraction. These optional files are excluded from source control by the supplied `.gitignore`.

Recreate Figure 7 and Supplementary Figures S1–S2 from the retained data, without rerunning the model:

```bash
python plot_article_figures.py --data-root data --output figures_rerun
```

The selected Figure 7 dataset is `data/rk2_N400_cfl01`. The script writes PNG, PDF and SVG files. For a completed fresh five-case calculation, use:

```bash
python plot_article_figures.py --data-root rerun --prefix '' --output figures_rerun
```

Recheck conservation and chemical equilibrium in the five retained cases:

```bash
python verify_saved_states.py data/rk2_N100_cfl02 data/rk2_N200_cfl02 data/rk2_N200_cfl01 data/rk2_N400_cfl02 data/rk2_N400_cfl01 --report saved_state_checks.json
```

Recalculate the refinement assessment:

```bash
python assess_publication.py --coarse data/rk2_N200_cfl02 --fine data/rk2_N400_cfl02 --time-refined data/rk2_N400_cfl01 --extra-coarse data/rk2_N100_cfl02 --extra-time-refined data/rk2_N200_cfl01 --out publication_assessment.json
```

The saved-state checker expects the canonical 36-hour cases; do not use it on the short installation check. Acceptance thresholds are in `verification_criteria.json`.

## Formulation and scope

The example represents a homogeneous, saturated, hydraulically closed 0.10-m column under a 20-V electrolyte potential difference. The five aqueous species are H⁺, OH⁻, Cu²⁺, Na⁺ and NO₃⁻. Nernst–Planck transport and current continuity are coupled to Faradaic electrode sources and local water, sorption and precipitation equilibria. Net water flow is zero. See [METHODS_AND_VERIFICATION.md](METHODS_AND_VERIFICATION.md) for the equations, initial conditions and numerical settings.

Copper boundaries are blocking: the example describes redistribution and phase transfer without copper recovery. It has not been calibrated or validated against an experiment. Raw precipitate peaks and fine instantaneous-current features remain mesh sensitive; the reported refinement criteria apply to the stated integrated quantities. Aqueous Cu represents free Cu²⁺ only. Activities are ideal, and matrix buffering, finite sorption capacity, electrode overpotential, gas and thermal effects are omitted.

Figure 7 shows pH, Cu phase inventories and cumulative charge. Figure S1 compares 100-, 200- and 400-cell calculations; Figure S2 compares time-step controls at 400 cells. Charge is integrated over accepted stages, not reconstructed from sparse instantaneous samples.

## Citation and distribution

The complete `EK1D_Article_Release.zip` is the journal reproduction archive named in the manuscript. This source package and the separate supplements provide a smaller distribution of the same model and retained data. Archive-specific packaging utilities are retained only in that complete archive. `SOURCE_UPDATE.json` in the numerical supplement records the driver documentation and diagnostic-plot corrections. Historical datasets keep their original source hashes; the numerical solver is unchanged.

The fixed version 2.1.0 reproduction archive is available from [Zenodo](https://zenodo.org/records/22925894), with version DOI [10.5281/zenodo.22925894](https://doi.org/10.5281/zenodo.22925894). Use the archived version for reproducing the article results; the main branch may contain later changes.
